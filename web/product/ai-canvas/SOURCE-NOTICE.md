# AI Canvas integration

This directory contains the production web build of [AI Canvas Tauri](https://github.com/Tenney95/AI-Canvas-tauri), integrated as the ComfyUI Studio AI Canvas page.

The original source-available license and copyright notice are preserved in [`LICENSE`](./LICENSE). The build is configured for browser mode and local ComfyUI at `http://127.0.0.1:8188`; Tauri-only capabilities such as native windows and local directory dialogs are not available in a browser tab.
